Which sound uses which recordings:
- activate - Heartbeat (single sound), 60 CC0 Sci-Fi SFX sfx_06b, Impact Sounds impactPunch_heavy_000, Electricity Game Sound Pack hit, Warp Engine Engage Sound
- release - 60 CC0 Sci-Fi SFX sfx_06b (reversed), Wind, hit, time morph megaswosh1, Metal Impact Sounds clink2
- loop - Reversing Time / Stuck in Time, Sci-Fi Sounds spaceEngineLow_002
- install - SFX - Plug In, Plug Out (Plug-in), Interface Sounds confirmation_004, 68 Workshop Sounds drill short 2
- warn - 50 CC0 Sci-Fi SFX beep_01
- deny - Interface Sounds error_005
- psycho_static - Sci-Fi RTS War Unit Sounds (radio), Electricity Game Sound Pack crackle, Interface Sounds glitch_002 and glitch_004
- psycho_ringing - Metal Impact Sounds bing1
